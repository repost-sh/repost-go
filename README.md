# repost-go

Official [Repost](https://repost.sh) client SDK for Go — typed webhook senders generated from your `.repost` schema.

> **Read-only mirror.** Source of truth is the Repost monorepo; this repository is synced and tagged automatically on each Go SDK release. Please do not open pull requests here — report issues at [repost-sh](https://github.com/repost-sh).

The first release will land here together with `go get` instructions and a quickstart.
